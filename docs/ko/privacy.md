# OpenNoodoe 개인정보처리방침
개발자: Veritas Studio
수정일: 2026년 9월 16일
문의: shin6361@gmail.com

OpenNoodoe는 Bluetooth로 호환 계기판에 직접 연결합니다. 회원가입, 인터넷 권한, 광고·분석 SDK가 없으며 개발자에게 데이터를 자동 전송하지 않습니다.

기기 내 처리 정보
선택한 사진, 가져온 테마, 설정, Bluetooth 기기 정보, 계기판·시스템 정보, 마지막으로 확인한 ODO 값과 진단 기록을 기기에서 처리하고 저장합니다. 기록에는 기기 식별자, Bluetooth 주소, 휴대폰·Android 정보, 명령과 계기판 응답이 포함될 수 있습니다.

권한과 계기판 전송
Bluetooth 권한은 기기 검색과 통신에 사용합니다. Android 11 이하의 위치 권한은 Bluetooth 검색용이며 위치를 추적하지 않습니다. 알림은 연결 서비스 상태를 표시합니다. 파일은 Android 선택 화면을 통해 지정합니다. 해당 기능을 사용하면 사진·테마·설정·시간 명령이 페어링된 계기판으로 전송됩니다.

보관과 삭제
앱 저장공간을 지우거나 앱을 제거하면 로컬 앱 데이터를 삭제할 수 있습니다. 휴대폰의 다른 위치에 있는 원본 파일, 별도 복사본과 계기판에 전송된 콘텐츠는 각각 관리해야 합니다. Android 시스템 백업이 허용되어 있으며 백업·기기 이전 여부는 기기와 OS 설정에 따릅니다. 개발자는 이 백업 서비스를 운영하지 않습니다.

문의와 외부 서비스
이메일 문의 시 자발적으로 제공한 정보는 답변과 문제 조사에 사용합니다. 로그를 보내기 전에 개인정보를 가려 주세요. 위 이메일로 제공한 정보의 삭제를 요청할 수 있습니다. 이메일, Google Play 및 별도로 제공되는 베타 신청 폼에는 각각 해당 서비스의 개인정보 안내가 적용됩니다.
