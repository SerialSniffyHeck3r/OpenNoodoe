# Changelog / 변경 기록

## 0.10.1 — 2026-10-20

- Rename ReNudo to OpenNoodoe in the launcher, five UI locales, service text, generated content labels, project and signing-property names.
- Preserve package `io.opennoodoe.app`; increment versionCode 36 → 37.
- Separate the obsolete private CFW installer integration from the stock companion.
- Publish stock companion source under MIT with Veritas Studio / SerialSniffyHeck3r attribution; add an offline license dialog and bundled notice.
- Provide Korean/English protocol and research documentation, standalone codec/ZIP tools and cross-language test vectors.
- Preserve photos, clock/speedometer import, settings, time, welcome light, system data and read-only ODO scope; no official themes bundled.
