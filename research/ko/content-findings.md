# 콘텐츠 처리 분석

공식 앱 실행 분석에서 원본 Creation ZIP과 컴파일된 전송 번들을 구분했습니다. 전송 번들은 JSON 위젯 그래프와 이미지로 구성됩니다. 모든 테마가 480×480 이미지 한 장이라는 가정을 바로잡았고 원본 ZIP을 그대로 올릴 수 없는 이유를 확인했습니다.

사진 경로는 480×480 품질 80 JPEG 끝에 슬롯 바이트를 붙입니다. 슬롯 6 전송은 11816, 11816, 883바이트 청크를 사용했고 관측된 마지막 DONE은 약 6.8초 걸렸습니다. 파일 식별자·제한 시간 처리에 반영했습니다.

직접 생성한 배경 전용 CFG는 전송됐지만 시계·속도계 위젯이 없어 렌더러 타입을 정하지 못했습니다. import는 지원 위젯을 판별합니다. 로컬 템플릿 편집기는 배경과 일부 글리프·막대 설정을 바꾸고 MD5 참조를 다시 생성합니다.

2026-09-03 내비게이션 실험은 DATA task 하나를 유지하며 메타데이터·이미지를 갱신했습니다. DONE 직후 복귀하던 현상 대신 내비게이션 화면을 유지했습니다. 레이더 creation은 인식했으나 POI 마커·좌표 의미는 부분적으로만 구분했습니다. 이 프로토콜은 배포 앱 기능이 아닌 참고 자료로 남깁니다.

공개 도구는 사용자가 만든 입력을 패키징합니다. 복구한 순정 테마·개인 사진·공식 앱 디컴파일 구현·펌웨어 바이너리는 연구노트에 포함하지 않습니다.
