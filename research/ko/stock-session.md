# 2026-08-31 순정 세션

대상은 AK550 SAA1AA(KR), PCBA SR0701, 실행 펌웨어 5.16, 리소스 5.14, 부트 0.15입니다. 기기별 MAC·시리얼·PIN·ODO는 여기서 제외했습니다.

82바이트 DEVICE_INFO 응답 4회, 성공한 11바이트 RIDING_STATUS 2회, 139바이트 OQC 읽기 2회를 기록했습니다. MOBILE_STATUS 3회가 성공했습니다. 앱 알림 10회가 성공했고 소유자가 표시를 확인했습니다. 라이트 15회 중 8회 성공, 7회 invalid-state였습니다.

라이트 응답은 시동 상태에 대응했습니다. ON에서는 status 5/state 0, C3=0 이후 ON/OFF 명령은 status 0과 요청 상태를 반환했고 실제 작동도 확인했습니다. 해당 세션의 연결된 명령에서는 시퀀스 재시도·프레임 파싱 실패가 없었습니다. CFW와 별개인 순정 휴대전화 프로토콜의 근거입니다.

생산 정보의 펌웨어 필드는 실행 DEVICE_INFO 버전과 달랐습니다. 호환 버전은 실시간 DEVICE_INFO로 보고해야 합니다. 정지 시간 단위는 확정하지 않았으므로 정수를 그대로 보존합니다.
