# Android source

[Build and install](../docs/en/quickstart.md) · [빌드·설치](../docs/ko/quickstart.md)

Open this directory in Android Studio. Package: `io.opennoodoe.app`. App and project name: **OpenNoodoe**. Version: **0.10.1 (37)**.

Release signing uses `-PopenNoodoeSigningProperties=/path/to/local.properties`. Signing keys, official themes, device evidence and CFW installer code are outside this source tree.
